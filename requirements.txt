# LLM Pipeline Generator — unified venv requirements.
#
# Installs every Python package in this repo as editable, with its [dev] extras
# (pytest, ruff, mypy, …). One venv at the repo root drives everything:
# worker, conventions, eval, API.
#
# Install with:
#   pip install -r requirements.txt
#
# Order matters — agent-worker must be installed before the API,
# which imports from it directly.

-e ./agent-worker[dev]
-e ./agent-conventions[dev]
-e ./agent-eval[dev]
-e ./agent-api[dev]
