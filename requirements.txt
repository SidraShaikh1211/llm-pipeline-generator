# Saturn Agent — unified venv requirements.
#
# Installs every Python package in this repo as editable, with its [dev] extras
# (pytest, ruff, mypy, …). One venv at the repo root drives everything:
# worker, conventions, eval, API.
#
# Install with:
#   pip install -r requirements.txt
#
# Order matters — saturn-agent-worker must be installed before the API,
# which imports from it directly.

-e ./saturn-agent-worker[dev]
-e ./saturn-agent-conventions[dev]
-e ./saturn-agent-eval[dev]
-e ./saturn-agent-api[dev]
